# 🤖 NLP Chatbot using Hugging Face Transformers

## 📌 Project Overview
This project demonstrates a conversational chatbot built using a pre-trained transformer model (DialoGPT) from Hugging Face. The chatbot can interact with users and generate human-like responses dynamically.

## 🎯 Objective
To build an AI chatbot capable of natural conversation using transformer-based models.

## 🛠️ Technologies Used
- Python
- Hugging Face Transformers
- PyTorch
- Jupyter Notebook

## ⚙️ Features
- Interactive chatbot
- Dynamic response generation
- Maintains conversation flow
- Exit functionality (exit/quit)

## 🧠 Model Used
- microsoft/DialoGPT-medium
